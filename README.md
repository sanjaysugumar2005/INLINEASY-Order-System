# 🍽️ INLINEASY — Restaurant Order System

A modern and responsive restaurant ordering web application designed to provide a smooth digital ordering experience from login to order tracking.

## ✨ Features

- 🔐 User Login
- 🏠 Restaurant Home Page
- 🍔 Digital Food Menu
- 🛒 Add to Cart
- ➕ Quantity Management
- 💳 Checkout
- ✅ Order Confirmation
- 🎫 Order Tracking
- 📱 Responsive UI
- 🎨 Modern Premium Design

## 🔄 Complete Order Flow

Login → Home → Menu → Cart → Checkout → Success → Track Order

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
- Git & GitHub
