## 📌 Project Overview

**INLINEASY** is a web-based restaurant ordering system that allows customers to browse food items, manage their cart, place orders, receive order confirmation, and track their order status.

The project focuses on creating a simple, responsive, and user-friendly digital ordering experience.

## ⚙️ How to Run Locally

### 1. Clone the Repository

```bash
git clone https://github.com/sanjaysugumar2005/INLINEASY-Order-System.git
```

### 2. Open the Project

```bash
cd INLINEASY-Order-System
```

### 3. Start the Backend

```bash
cd backend
python3 app.py
```

The Flask backend will run locally.

### 4. Start the Frontend

From the project directory:

```bash
python3 -m http.server 5500
```

Then open the local website in your browser.
